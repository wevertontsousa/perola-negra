# Visão Geral do Projeto

## Contexto

O cliente deseja criar uma loja online para vender roupas e possíveis acessórios. Atualmente as roupas são divulgadas através de redes sociais e de loja física.

---

## Público-alvo

Clientes interessados em roupas, independente da faixa etária e gênero.

---

## Escopo

### Funcionalidades Essenciais

- Catálogo
    - Lista de produtos
    - Detathes do produto
- Checkout
    - Carrinho de compras
    - Contato
    - Endereços de entrega e cobrança
    - Pagamento (Pix ou Dinheiro)
    - Realizar pedido
- Autenticação
    - Login
    - Logout
- Cliente
    - Lista de pedidos
    - Dados pessoais
- Administração
    - Gerenciar produtos
    - Gerenciar pedidos
    - Gerenciar usuários

---

## Fora do Escopo

- Pagamento via boleto
- Login via redes sociais
- Cupons de desconto e avaliações
- App mobile nativo
- Histórico detalhado/log de alterações de pedidos
- Sistema de logística/rastreio automático
